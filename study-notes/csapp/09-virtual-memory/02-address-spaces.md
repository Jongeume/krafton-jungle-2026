# 9.2 주소 공간

> 진척도 이슈 : [#200](https://github.com/Jongeume/krafton-jungle-2026/issues/200)

> [!NOTE]
> **요약**  
> 주소공간 = 주소로 쓰는 **정수의 집합**.  
> 가상주소공간 {0 … N−1}, N = 2^n  
> 물리주소공간 {0 … M−1}, M = 2^m

> [!TIP]
> **비유**  
> 사물함 번호를 3자리 숫자로만 적기로 하면 000 ~ 999, 1000 가지다.  
> 이진수 n 자리로 적으면 0 ~ 2^n − 1, 2^n 가지다.  
> 이 번호 목록 자체가 주소공간이다.

## 주소 공간

- 선형 주소 공간 = 주소 공간의 정수가 **연속적** {0, 1, 2, …}  
- 주소 공간의 크기 = 가장 큰 주소를 표시하는 데 필요한 비트 수 (N = 2^n)  
    - 예 : {0, 1, 2, … N−1}  
    - 정정 : 0 부터 시작

| | 집합 | 크기 | 무엇 |
| --- | --- | --- | --- |
| 가상주소공간 | {0, 1, 2, … N−1} | N = 2^n | n 비트 주소 공간 (32비트 or 64비트) |
| 물리주소공간 | {0, 1, 2, … M−1} | M = 2^m | M 바이트의 물리 메모리에 대응 |

## 주소공간이라는 개념이 주는 것

- 데이터 객체와 그 특성(주소)을 명확히 구별한다  
    - ~~= 정렬과 관련?~~  
    - **정정** : 정렬과 무관  
        - 데이터 객체 = 바이트  
        - 특성 = 주소  
- 각 데이터 객체가 **다중 독립 주소**를 가질 수 있다  
    - 각 주소는 서로 다른 주소공간에서 고른다  
- 메인 메모리의 각 바이트는 주소를 둘 가진다  
    - 가상주소공간에서 고른 **가상주소**  
    - 물리주소공간에서 고른 **물리주소**
