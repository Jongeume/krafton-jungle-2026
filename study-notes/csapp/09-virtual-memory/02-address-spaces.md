# 9.2 주소 공간

> 진척도 이슈 : [#200](https://github.com/Jongeume/krafton-jungle-2026/issues/200)

선형 주소 공간 = 주소 공간의 정수가 **연속적** {0, 1, 2,...}

주소 공간의 크기 = 가장 큰주소를 표시하는데 필요한 비트 수 (N=2^n)  
ex) {0, 1, 2, .... N-1}  (정정 : 0부터 시작)

가상주소공간 =  ex) n 비트 주소 공간 (32비트 or 64비트 가상주소공간 지원.)  
- {0, 1, 2, ... N-1}  
- 크기: N = 2^n

물리주소공간 = M 바이트의 물리 메모리로 대응  
- {0, 1, 2, ... M-1}  
- 크기: M = 2^m

- 주소공간의 개념은 데이터 객체와 그들의 특성(주소들) 간에 명확한 구별을 해줌 (~~= 정렬과 관련?~~ → 정렬과 무관. 데이터 객체 = 바이트, 특성 = 주소라는 뜻)  
- 각 데이터 객체가 **다중 독립 주소**를 가질 수 있게함.  
- 각 주소는 서로 다른 주소공간에서 선택.  
- 메인 메모리의 각 바이트는 가상 주소공간에서 선택된 가상주소를 가짐. 그리고 물리 주소공간에서 선택된 물리주소도 가진다.
