# 9장 들어가며 — 가상메모리

> 진척도 이슈 : [#198](https://github.com/Jongeume/krafton-jungle-2026/issues/198)

## 가상메모리 (VM)

- 메인 메모리의 추상화를 제공  
- 각 프로세스에 주소공간 제공

## 주요 기능

(1) 메인 메모리를 디스크 주소공간의 **캐시**로 취급  
- 활성화 영역만 유지  
- 데이터를 디스크와 메모리 간에 필요에 따라 전송. (demand paging, 요구 페이징)  
(2) 각 프로세스에 통일된 주소공간 제공 - 메모리 관리 단순화  
(3) 각 프로세스의 주소공간을 다른 프로세스로 부터 손상 보호

## 주요 특징

- 시스템 설계의 **중심**에 있음 — 여러 곳에 스며 있다 (하드웨어 예외, 어셈블러, 링커 ,로더, 공유객체, 파일, 프로세스 등등...)  
- 메모리를 다른 프로세스와 공유  
- 메모리 위치에서 읽기/쓰기로 디스크 파일의 내용 수정 및 읽기 가능

## 궁금한점

- 주소공간  
- 메모리블록에서의 매핑의 의미  
- 명시적인 복사 -
