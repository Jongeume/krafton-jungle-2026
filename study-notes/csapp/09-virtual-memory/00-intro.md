# 9장 들어가며 — 가상메모리

> 진척도 이슈 : [#198](https://github.com/Jongeume/krafton-jungle-2026/issues/198)

> [!NOTE]
> **요약**  
> 가상메모리(VM) = 메인 메모리의 **추상화**.  
> 각 프로세스에 자기 **주소공간**을 준다.

> [!TIP]
> **비유**  
> 가상메모리 = 프로세스마다 받는 "나만 쓰는 큰 창고의 지도".  
> 실제 물건은 서고(디스크)에 있고, 자주 쓰는 것만 책상(DRAM)에 꺼내 둔다.  
> 지도의 번호(가상주소)를 실제 위치(물리주소)로 바꾸는 건 관리실(MMU)이 한다.

## 주요 기능

1. 메인 메모리를 디스크 주소공간의 **캐시**로 취급  
    - 활성화 영역만 유지  
    - 필요할 때 디스크 ↔ 메모리 전송 (demand paging, 요구 페이징)  
2. 각 프로세스에 통일된 주소공간 제공  
    - 메모리 관리 단순화  
3. 각 프로세스의 주소공간을 보호  
    - 다른 프로세스로부터의 손상

## 주요 특징

- 시스템 설계의 **중심**에 있다 — 여러 곳에 스며 있다  
    - 하드웨어 예외  
    - 어셈블러 · 링커 · 로더  
    - 공유 객체  
    - 파일  
    - 프로세스  
- 메모리를 다른 프로세스와 공유  
- 메모리 위치를 읽고 쓰는 것으로 디스크 파일을 읽고 수정

## 궁금한 점

- 주소공간  
- 메모리 블록에서 매핑의 의미  
- 명시적인 복사
